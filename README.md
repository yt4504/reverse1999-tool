# リバース1999ツール

GitHub Pages 公開用ファイルです。

## 公開方法

このフォルダ内のファイルを GitHub リポジトリのルートへアップロードし、Settings → Pages で `main` / `root` を公開元に指定してください。

## データ移行

PCのローカル版で「データ保存」を押すと `reverse1999-tool-data-YYYY-MM-DD.json` が保存されます。
公開版で「データ読込」を押してそのJSONを選択すると、所持キャラ・P・共鳴・編成・FREE編成・表示設定を移行できます。
